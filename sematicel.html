The Sematic Elements

Semantic elements clearly describe their meaning in a human- and machine-readable way. Elements such as 

        <header>,
        <footer> 
        <article> 
        <figcaption>
        <details>
are all considered semantic because they accurately describe the purpose of the element and the type of content that is inside them.

The Non-Semantic Elements

Non-semantic elements tell nothing about their content. Examples of non-semantic elements are 

        <div> and <span>
The <div> element is used as a container for HTML elements - which has no special meaning. The <span> element is used to group inline-elements in a document - which also has no special meaning.
